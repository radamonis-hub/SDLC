# Приложение для определения гликемического индекса продуктов

Автор: Адамонис Р. А.  
Дисциплина: «Жизненный цикл разработки ПО»

## Описание проекта

Проект представляет собой настольное приложение для определения гликемического индекса (ГИ) продуктов питания по их названию.

Приложение предусматривает ввод названия продукта через отдельную форму, отображение соответствующего значения гликемического индекса на главном экране, сохранение последнего введённого продукта и восстановление ранее введённых данных при повторном открытии формы.

При вводе некорректных данных программное средство должно уведомлять пользователя об ошибке.

## Используемые технологии

Язык программирования: Java.
Платформа разработки интерфейса: JavaFX.
Система сборки: Apache Maven.
Среда разработки: IntelliJ IDEA.
