# Изменённый план разработки CaterFlow

## 1. Основание для изменения плана

План пересмотрен по результатам второго раунда переговоров с заказчиком.

В состав требований внесены следующие изменения:

| Изменение | Трудоёмкость |
|---|---:|
| Добавление выгрузки заявки в PDF | +8 ч |
| Отмена сохранения вариантов меню | -8 ч |
| Перенос истории заказов на последующие этапы | -8 ч |
| **Изменение общей трудоёмкости** | **-8 ч** |

Первоначальная трудоёмкость составляла 274 человеко-часа. После изменения состава работ она составляет 266 человеко-часов.

## 2. Изменения требований и приоритетов

| Требование | Изменение | Новый приоритет |
|---|---|---:|
| SYS-FUNC-013 — История заказов клиента | Перенесено на будущее | 40 |
| SYS-FUNC-014 — Сохранение вариантов меню | Исключено из текущей версии | — |
| SYS-FUNC-025 — Выгрузка заявки в PDF | Добавлено | 20 |

История заказов сохраняется в перечне перспективных требований, но не входит в объём текущей разработки. Сохранение вариантов меню исключено из согласуемой версии продукта.

## 5. Результат пересмотра

Изменения позволили сократить первоначальную оценку на 8 человеко-часов и включить новую функцию выгрузки заявки в PDF.

При этом основной сценарий работы системы сохранён: клиент выбирает блюда, формирует меню, рассчитывает стоимость и отправляет заявку, а менеджер получает и обрабатывает её.

Срок разработки остаётся равным 12 неделям. Для выполнения обновлённого объёма работ принято решение рассмотреть привлечение младшего разработчика.
