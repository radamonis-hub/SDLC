# Глоссарий проекта CaterFlow

| Термин | Определение |
|---|---|
| CaterFlow | Разрабатываемая информационная система для автоматизации формирования и обработки заявок на организацию кейтерингового обслуживания. |
| Кейтеринг | Организация питания и обслуживания мероприятий с предоставлением блюд, напитков и сопутствующих услуг. |
| Клиент | Пользователь системы, который просматривает каталог, формирует меню и отправляет заявку на обслуживание мероприятия. |
| Менеджер | Сотрудник компании, ответственный за рассмотрение, обработку и изменение статусов заявок клиентов. |
| Администратор | Пользователь, обладающий правами управления каталогом блюд, категориями, ценами, готовыми наборами и доступностью позиций. |
| Гость | Посетитель веб-приложения, который не прошёл авторизацию, но может просматривать каталог, формировать меню и оформлять заявку без регистрации. |
| Каталог блюд | Структурированный перечень доступных блюд и напитков с описаниями и ценами. |
| Категория блюд | Группа каталога, объединяющая позиции по общему признаку. |
| Блюдо | Отдельная позиция каталога, которую клиент может включить в формируемое меню. |
| Готовый набор | Предварительно сформированная комбинация блюд, предлагаемая клиенту как единый вариант меню. |
| Меню | Совокупность выбранных клиентом блюд и напитков, предназначенная для последующего расчёта стоимости и оформления заявки. |
| Заявка | Зарегистрированный в системе запрос клиента на организацию кейтерингового обслуживания с указанными параметрами мероприятия и составом меню. |
| Статус заявки | Текущее состояние обработки заявки, определяющее этап её жизненного цикла. |
| Расчёт стоимости | Определение предварительной стоимости сформированного меню и сопутствующих услуг на основании заданных параметров. |
| Стоимость доставки | Денежная сумма, рассчитываемая системой с учётом установленных условий доставки. |
| Аутентификация | Процесс проверки подлинности пользователя на основании предоставленных учётных данных. |
| Авторизация | Предоставление пользователю доступа к функциям системы в соответствии с его ролью и правами. |
| Учётная запись | Совокупность данных, идентифицирующих зарегистрированного пользователя в системе. |
| Вариант использования | Описание взаимодействия актора с системой для достижения определённой цели. |
| Актор | Внешняя по отношению к системе роль, которая взаимодействует с её функциями. |
| Модульный монолит | Архитектурный подход, при котором приложение является единым развёртываемым компонентом, внутренне разделённым на функциональные модули. |
| Диаграмма вариантов использования | UML-диаграмма, отображающая акторов системы, доступные им варианты использования и отношения между ними. |
