
# Первоначальный план разработки CaterFlow

## 1. Общие сведения

**Проект:** CaterFlow  
**Заказчик:** кейтеринговая компания «ФуршетПро»  
**Планируемый срок разработки:** 3 месяца (12 недель).  
**Первоначальная трудоёмкость:** 274 человеко-часа.

План разработан на основании спецификации требований к ПО, системных требований и первоначальной оценки трудоёмкости.

Разработка разделена на три итерации. При распределении требований учитываются их приоритеты и зависимости между функциями. Каждая последующая итерация использует результаты предыдущих.

## 4. Зависимости между требованиями

При планировании учитываются следующие основные зависимости:

| Предшествующее требование | Зависимое требование | Обоснование |
|---|---|---|
| SYS-FUNC-001 | SYS-FUNC-002 | Для просмотра каталога необходимо обеспечить хранение данных блюд |
| SYS-FUNC-021 | SYS-FUNC-001 | Управление данными каталога требует реализации операций добавления и изменения блюд |
| SYS-FUNC-022 | SYS-FUNC-007 | Расчёт стоимости блюд зависит от наличия актуальных цен |
| SYS-FUNC-002 | SYS-FUNC-004 | Для формирования меню клиент должен иметь доступ к каталогу |
| SYS-FUNC-023 | SYS-FUNC-003 | Использование готовых наборов зависит от возможности их предварительного создания |
| SYS-FUNC-004 | SYS-FUNC-007 | Для расчёта стоимости необходимо получить состав меню |
| SYS-FUNC-007 | SYS-FUNC-009 | Общая стоимость зависит от стоимости выбранных блюд |
| SYS-FUNC-008 | SYS-FUNC-009 | Расчёт итоговой стоимости учитывает стоимость доставки |
| SYS-FUNC-009 | SYS-FUNC-010 | Для оформления заявки необходимо получить предварительную стоимость заказа |
| SYS-FUNC-010 | SYS-FUNC-011 | После заполнения формы заявка должна быть сохранена |
| SYS-FUNC-018 | SYS-FUNC-015 | Доступ менеджера к заявкам требует авторизации сотрудника |
| SYS-FUNC-015 | SYS-FUNC-016 | Для работы со статусами необходимо обеспечить просмотр заявок |
| SYS-FUNC-011 | SYS-FUNC-019 | Уведомление менеджера отправляется после поступления новой заявки |

## 5. Предварительные условия реализации

1. Разработка выполняется последовательно в рамках трёх итераций.
2. Результаты каждой итерации проверяются перед переходом к следующей.
3. Требования к безопасности и надёжности учитываются на протяжении всего процесса разработки.
4. При выявлении новых требований или изменении существующих оценка трудоёмкости и план итераций подлежат пересмотру.
5. В рамках первоначального плана предполагается выполнение работ одним основным разработчиком.

## 6. Заключение

Первоначальный план предусматривает реализацию всех 24 функциональных и 14 нефункциональных системных требований за три итерации общей продолжительностью 12 недель.

Наиболее значимые функции, обеспечивающие формирование меню и оформление заявки, распределены с учётом необходимых предварительных компонентов. Дополнительные возможности личного кабинета и управления заказами предусмотрены в третьей итерации.

План является предварительным и может быть изменён по результатам дальнейших переговоров с заказчиком.
